# Wakhid Pangestu — Portfolio

Personal portfolio website built with **Next.js 16**, **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Content Collections**.

Live site: [wakhidpangestu.vercel.app](https://wakhidpangestu.vercel.app)

## Selected Projects

- **ZAP (Zero Answer Policy)** (`LOGICODIX 2026 · #10 Top Semifinalist`) — Socratic cognitive AI math tutor and real-time 3D interactive whiteboard powered by Three.js/WebGL and SymPy deterministic verification. ([GitHub](https://github.com/wakhidpangestu/ZAP) · [Website](https://chatzap.web.id))
- **Zaky** (`UINIC 8.0 · #9 Top Semifinalist`) — Federated zakat distribution verification network featuring 4-eyes segregation, append-only hash-chain audit trails, Ed25519 cross-institutional cryptographic attestation, and an interactive 3D office simulation. ([GitHub](https://github.com/wakhidpangestu/zaky) · [Website](https://zakyapp.vercel.app))
- **Guyub** (`GDGoC ITB STACK 2026 · Top Semifinalist`) — All-in-one event operations platform for communities and campus organizations built with Flutter Web & Firebase. ([GitHub](https://github.com/wakhidpangestu/guyub) · [Website](https://guyubapp.web.id))
- **Pandu** (`ETHJKT Hackathon · #12 · 2026`) — Web3 real-world asset (RWA) project exploring onchain rails for real-world assets. ([GitHub](https://github.com/PANDUWEB3/pandu) · [Website](https://www.panduweb3.my.id))

## Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Language:** TypeScript, React 19
- **Styling:** Tailwind CSS v4, Radix UI, Lucide Icons, Motion
- **Content:** Content Collections + MDX

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
npm run build
npm run start
```
